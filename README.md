# CERTIFICADOSFINAL

Proyecto PoliSeguimiento (segundo avance).

## Estructura

- `PoliSeguimiento_Segundo_Avance_codigo/poliseguimiento-repo`: código del proyecto.
- `.github/workflows`: flujo de pruebas automáticas (CI).

## Cómo ejecutar las pruebas

    cd PoliSeguimiento_Segundo_Avance_codigo/poliseguimiento-repo
    npm install
    npm test

## Cómo contribuir

1. Crear una rama desde `main` (`tipo/nombre-corto`).
2. Hacer commits con prefijo: feat, fix, docs, test, chore, ci.
3. Abrir un pull request y esperar el check verde y una revisión.
